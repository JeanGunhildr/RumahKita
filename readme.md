# 🏡 RumahKita

**RumahKita** adalah platform marketplace properti yang dirancang untuk memudahkan pengguna dalam mencari, melihat, dan menawarkan rumah untuk dijual. Platform ini bertujuan mempertemukan calon pembeli dengan penjual rumah melalui website yang sederhana, informatif, dan mudah digunakan.

## ✨ Fitur Sementara

### Pengunjung & Pembeli
- 🏠 **Beranda** — Menampilkan informasi dan rekomendasi rumah.
- 🔎 **Pencarian Rumah** — Membantu pengguna menemukan rumah yang sesuai.
- 📄 **Detail Rumah** — Menampilkan informasi lengkap mengenai properti.
- 📰 **Artikel** — Menyediakan informasi seputar rumah dan properti.
- 🔐 **Autentikasi** — Registrasi dan login pengguna.

### Admin
- 📊 **Dashboard** — Mengelola informasi properti.
- ➕ **Tambah Rumah** — Menambahkan informasi rumah untuk dijual.

*Fitur di atas merupakan daftar dari rencana awal pengembangan dan mungkin akan bertambah lagi suatu saat*

## 🛠️ Teknologi

| Teknologi | Penggunaan |
|---|---|
| PHP Native | Logika aplikasi dan backend |
| HTML5 | Struktur halaman web |
| Tailwind CSS | Styling dan desain antarmuka |
| JavaScript | Interaktivitas pada halaman |
| MySQL | Penyimpanan data |
| Apache | Web server lokal melalui XAMPP |
| Git & GitHub | Version control dan kolaborasi |
